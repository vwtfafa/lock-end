EndLock

Lock the End dimension on your Paper server.

Download Docs Changelog Issues

What it does

One command locks or unlocks travel into the End — portals, teleports, and most plugin-driven travel included. Useful for progression servers, events, or seasons where the End should stay closed until you say otherwise.

Requirements

  • Paper 26.2+
  • Java 25
  • No required dependencies

Quick start

  1. Download the JAR from Releases
  2. Drop it into plugins/
  3. Restart the server
  4. Run /endlock lock

Commands

CommandDescription
/endlock lockLock the End
/endlock unlockUnlock the End
/endlock statusShow current state
/endlock unlockin 7dLock and auto-unlock after duration
/endlock unlockat 2026-07-01 18:00Lock until a date/time
/endlock statsLock / block counters
/endlock exportExport JSON logs

Integrations

  • PlaceholderAPI — %lockend_status%, %lockend_remaining%, %lockend_blocked_count%
  • LuckPerms — context lockend_locked=true/false
  • DiscordSRV — optional channel notifications (set channel ID in config)
  • MiniMessage — colored messages in language files

Releases

Stable builds come from master. One experimental beta build is published from the beta branch and replaced on each push.
